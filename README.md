# Marwan Mostafa — Data Analyst Portfolio

A responsive static portfolio website built with HTML, CSS and JavaScript.

## Files
- `index.html` — main website
- `style.css` — responsive styling and dark/light theme
- `script.js` — mobile menu, theme toggle, scroll reveal and dynamic year
- `assets/Marwan_Mostafa_Data_Analyst_Portfolio.pdf` — portfolio PDF

## GitHub Pages
1. Create a public repository named `portfolio`.
2. Upload all files while keeping the `assets` folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select **main** and **/(root)**, then press **Save**.
6. GitHub will show the live website URL.
